# Architecture Decision Records

One file per decision, `NNNN-<slug>.md` (4 digits, kebab-case slug), copied from [0000-template.md](0000-template.md)
and kept under 60 lines. The agent brings 2–3 options, least code first, with evidence; the user decides; the agent
records only what the user approved. Accepted ADRs are the source of truth for the stack. When a decision changes, a
new ADR supersedes the old one, and the old one's status says `superseded by NNNN`.
